# Verified Kitchen

Verified Kitchen is a privacy-preserving AIoT and blockchain-based hygiene monitoring framework for cloud kitchens.

## Applications

- Web Dashboard — Next.js
- Mobile Application — Flutter

## Services

- Backend — NestJS
- AI Service — Python / YOLO
- IoT — ESP32 / MQTT
- Blockchain — Hyperledger Fabric
- Database — PostgreSQL / Supabase
